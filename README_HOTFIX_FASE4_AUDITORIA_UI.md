# Hotfix Fase 4 · Auditoría UI

## Objetivo
Dar más aire visual a la pantalla **Admin > Bitácora / Auditoría**, especialmente en la zona superior: tarjetas de métricas, listas de actividad, filtros y tabla de eventos.

## Cambios incluidos
- Aumenta padding interno de tarjetas y encabezados.
- Mejora separación vertical en tarjetas de métricas.
- Refuerza el espaciado de listas internas y badges.
- Mejora legibilidad de formularios de filtro.
- Agrega más aire en celdas de la tabla de auditoría.
- Mantiene la estructura funcional y no toca base de datos.
